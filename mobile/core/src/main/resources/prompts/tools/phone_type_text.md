Type the whole text into one field in a single call. Target it with ref+snapshotId, or name it in element (label, accessible name or placeholder; it must match exactly one input field now, otherwise the result lists the matches or asks you to observe). pressEnter submits afterwards. The result reads the field back: readback is what it shows now (hidden for password fields), readbackMatches whether it is the intended text; text that did not land is retried once. See Calling tools in the system prompt for effect.kind. On a screen the element list cannot read, give the box's point instead: x+y (a visibleText center) or the @vN ref from phone_find_visually; it taps there, pastes, then checks the screen text (match = it went in; point_not_typed = that point did not take it, so find the box again instead of repeating). Without a ref or point the text goes into whichever box holds focus; no_focus means give the point. Name the box in element in a few words (e.g. the message box at the bottom) and, when the list has no matching field, it is found by sight and typed into at its point; foundBySight and seen say what was used.
