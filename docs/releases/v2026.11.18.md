## 主要变更

### 修复：4 处被 `except Exception` 静默吞掉的 TypeError

这些 bug 的共同表现是「功能完全不生效，日志只留一句 debug」，定位成本极高：

| 位置                   | 症状                                                                                                                        |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `app/schedulers.py`    | 只定义了 `hour`，没定义 `minute`；早晨问候与 `suggest_action` 分支每轮抛 `NameError`，**从未执行过**                        |
| `agent/context.py`     | `format_context_for_prompt` 不收 `uid` 但调用方传了；时间/位置/天气/用户状态/待办整段**从未进入系统提示词**                 |
| `agent/persona.py`     | `get_persona_prompt` / `contextual_response_style` / `get_current_mood` 同样不收 `uid`；人格段从未注入                      |
| `agent/preferences.py` | `list_preferences(uid)` / `set_preference(k,v,uid)` / `get_preference(k,uid)` 签名不匹配；偏好注入与「我住在X」写入长期失效 |

### 补齐两个孤儿模块的接线

`app/runtime_settings.py` 与 `agent/stepfun_keys.py` 代码完整但零引用：

- **设置中心**：新增 `GET/POST /api/settings`（批量写入，要么全改要么不改），OTA 响应新增 `device` 段（`XIAOZHI_OTA_DEVICE_ENABLE` 开关）。设备 OTA 地址不再编译进固件，服务器搬家可以提前下发。
- **StepFun 多 Key**：`STEPFUN_KEY` 支持逗号分隔多把，接入 TTS / LLM / 管理页校验三处。429 短冷却、401/403 长隔离、全冷却兜底不阻塞。

### 修复发布链路

包名改为 `@sxliuyu/allbot` 后 `npm pack` 产出 `sxliuyu-allbot-<ver>.tgz`，但 4 处仍按 `allbot-<ver>.tgz` 匹配，全部静默失败：

- `publish-tarball.yml`：tarball 变量为空，`gh release create` 缺文件参数失败
- `src/commands/android-install.ts`：找不到 asset，tarball 安装静默回退到 npm 全局安装
- `scripts/install.sh` / `install-termux.sh` / `release.sh`：下载链接 404

顺带修掉 `ls` 多通配符在未匹配时 exit 2 的问题（`pipefail` + `set -e` 会导致整步失败），改用 `find`。
